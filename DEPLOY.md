# Размещение сайта «КРОНА» на Timeweb и домене Рег.ру

Сайт работает с серверной отрисовкой (Node.js). Поэтому обычный «виртуальный хостинг с папкой
public_html» не подойдёт — нужен тариф, где можно запустить приложение Node.js:
**Timeweb Cloud → Приложения → Node.js** (самый простой вариант) либо облачный сервер (VPS).

## 1. Сборка

Требуется Node.js 20 или новее.

```bash
npm install
npm run build          # сборка
npm start              # запуск: сервер слушает порт из переменной PORT
```

Готовый сайт появляется в папке `.output`, точка запуска — `.output/server/index.mjs`.

## 2. Настройки для Timeweb Cloud (раздел «Приложение»)

| Параметр        | Значение                                           |
| --------------- | -------------------------------------------------- |
| Тип приложения  | Node.js (версия 20+)                               |
| Репозиторий     | ваш GitHub-репозиторий, ветка `main`               |
| Команда сборки  | `npm install && npm run build`                     |
| Команда запуска | `npm start`                                        |
| Порт            | `3000` (или тот, что подставляет Timeweb в `PORT`) |

### Переменные окружения

| Переменная                 | Значение                            |
| -------------------------- | ----------------------------------- |
| `NITRO_PRESET`             | `node-server` (обязательно)         |
| `VITE_SITE_URL`            | `https://ваш-домен.ru`              |
| `VITE_EMAILJS_SERVICE_ID`  | необязательно, по умолчанию текущий |
| `VITE_EMAILJS_TEMPLATE_ID` | необязательно, по умолчанию текущий |
| `VITE_EMAILJS_PUBLIC_KEY`  | необязательно, по умолчанию текущий |

`VITE_SITE_URL` задаётся **до сборки** — от него зависят адреса в превью для соцсетей,
`sitemap.xml` и `robots.txt`.

## 3. Домен в Рег.ру

1. Купите домен в Рег.ру (для России удобны зоны `.ru` или `.рф`).
2. В Timeweb в настройках приложения добавьте домен — Timeweb покажет IP-адрес
   (или CNAME для облачных приложений).
3. В Рег.ру откройте «Управление DNS» и добавьте записи:
   - `A` — имя `@` — IP-адрес от Timeweb;
   - `A` — имя `www` — тот же IP-адрес;
   - либо `CNAME`, если Timeweb выдал именно адрес вида `xxx.twc1.net`.
4. Дождитесь обновления DNS (обычно 1–4 часа, максимум сутки).
5. В Timeweb включите бесплатный SSL-сертификат (Let's Encrypt), чтобы сайт открывался по `https`.

## 4. После переезда

- Заявки с форм продолжают уходить через EmailJS на `krona.studio.mebel@yandex.ru` —
  никакой серверной почты настраивать не нужно.
- Добавьте сайт в Яндекс.Вебмастер и укажите `https://ваш-домен.ru/sitemap.xml`.
- Проверьте, что открываются: `/`, `/partners`, `/privacy`, `/consent`, `/cookie`, `/terms`,
  `/sitemap.xml`, `/robots.txt`.
